# Girishbhai Gandevikar Jewellers — organized static recreation

This project separates the homepage into readable files:

- `index.html` — page structure and content
- `style.css` — layout, typography, colors, responsive design
- `script.js` — mobile navigation and current year

## Run locally

Open `index.html` in a browser, or open this folder in VS Code and use the Live Server extension.

## Assets

Images, logo and hero video currently load from the public website at `girishbhaigandevikar.com`. Internet access is needed to load them. If you prefer a self-contained submission, download the assets and update the image/video URLs to local paths under `assets/`.

## Important note

The uploaded `.html` file is a saved, rendered page from a live Next.js website, not the original Next.js project source. This folder is a clean, editable static recreation of its homepage structure, not the exact original source code or all of its backend features. Navigation links to some sections open the original website.
